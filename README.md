# About This Project
Why do websites have to be scrolled vertically? Why not have one that moves horizontally? this question inspired this project.
My original idea was to create the path itself as one large line running through the middle of the page, with the user essentially moving along it while scrolling. However, making this work smoothly with a horizontal scrolling layout was more challenging than I expected. Instead of giving up on the idea, I reversed my perspective and made the colorful gradient background static, and created two long SVGs on the top and bottom so that they form a path in middle of them.The SVG shapes were an intentional choice since they give a sense of flexibility and freedom which connects to the larger idea behind the design: breaking away from established rules and finding freedom.
Another challenge was making the horizontal scrolling feel natural. People are used to scrolling up and down, so I designed the website to respond to normal up-and-down scrolling while translating that movement into horizontal progression.
The navigation bar also follows the user's movement through the page. The corresponding navigation item is highlighted as the user reaches each section.
